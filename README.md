# Todo App

A simple and intuitive task management application built with React and Vite. It helps users organize everyday tasks, track their progress, and manage their to-do list through a clean and responsive interface.

## Live Preview

[View the live application](<>)

## Technologies Used

- **React** — building the user interface with reusable components.
- **TypeScript** — adding static typing to JavaScript.
- **Vite** — development server and build tool.
- **React Router** — handling navigation and routing between pages.
- **SCSS (Sass)** — writing modular and maintainable stylesheets.
- **ESLint** — code quality and linting.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

## Features

- Add new tasks to the to-do list.
- View and manage existing tasks.
- Mark tasks as completed or active.
- Keep the task list organized with a simple interface.
- Responsive layout for different screen sizes.

> Remove or adjust any feature that is not implemented in your version of the app.
